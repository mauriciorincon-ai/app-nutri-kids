# Kit de prueba — Nutri-Kids

Materiales para recorrer la **guía de prueba** (`docs/GUIA-DE-PRUEBA.html`) sin tener que
inventar datos. Todo lo de aquí es de mentira y seguro de compartir.

## Qué hay

| Archivo                                                          | Para qué                                                                                                                                                                |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`../../data/demo-diet.json`](../../data/demo-diet.json)         | La **dieta demo** con la que arranca la app (inventada, anonimizada, bilingüe). Ya viene cargada; sirve para probar el semáforo, el chat y el registro sin cargar nada. |
| [`preguntas-calibracion-chat.md`](preguntas-calibracion-chat.md) | Preguntas listas para copiar en el **chat**, con lo que deberías ver en cada una (respuesta local instantánea, respuesta de IA, o redirección amable).                  |
| [`dia-de-registro-ejemplo.md`](dia-de-registro-ejemplo.md)       | Un **día de registro** de ejemplo para practicar marcar comidas con hora, poner notas y revisar "Días anteriores".                                                      |

## La dieta REAL no está aquí (a propósito)

El repositorio es público y **jamás** contiene la dieta real de un niño (regla de privacidad de la
app). Para el paso del gate que pide probar con la dieta oficial, ese archivo se entrega **aparte**,
por fuera del repo. Cárgalo desde **Cargar** solo en tu teléfono; vive únicamente ahí.

## Cómo usar el kit

1. Abre `docs/GUIA-DE-PRUEBA.html` en tu navegador (doble clic al archivo — no necesita internet).
2. Sigue los bloques. Cuando un paso mencione una pregunta del chat o un día de registro, este kit
   te da el texto exacto y lo que se espera.
3. Marca cada prueba en la guía (las casillas se guardan solas en tu navegador).
