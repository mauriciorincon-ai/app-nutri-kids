# Preguntas de calibración del chat

Copia estas preguntas en el **Chat** (con la **dieta demo** cargada) y compara con lo que deberías
ver. Desde el Sprint 4 **todo** se contesta en tu teléfono, con tu plan y **sin internet**: hay tres
tipos de respuesta — **del plan**, **«tu plan no lo dice»** y **redirección** (el chat no responde
eso a propósito). Si pones el teléfono en modo avión, todas deben salir igual.

## 1. «¿Esto se puede?» (tarjeta del semáforo)

| Escribe esto            | Deberías ver                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `¿la manzana se puede?` | 🔴 **Evitar** · "en descanso hasta el 28 sep 2026" · reemplazos: **pera, kiwi, uvas, fresas** · insignia **"Desde tu plan · sin IA"** |
| `¿el pollo se puede?`   | 🟢 **Se puede** (proteína del plan)                                                                                                   |
| `¿el banano se puede?`  | 🟡 **Con límite** · "máx. 1 al día"                                                                                                   |
| `gaseosa`               | 🔴 **Evitar** (con el porqué en palabras simples)                                                                                     |
| `¿la crema de maní?`    | 🔴 **Evitar** (restringida) · reemplazos: aguacate untado, queso fresco                                                               |

## 2. Preguntas abiertas (también salen del plan)

| Escribe esto                    | Deberías ver                                                                                                          |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `no tengo pollo, ¿qué le doy?`  | "Si no hay pollo…" y opciones **del plan** (huevos y otras proteínas del grupo), sin mencionar rojos                  |
| `no quiso el brócoli`           | "Pasa, y no es una falla" (sin regaño) · otras opciones del plan · bloque **"Lo que sigue"** con la próxima comida               |
| `no quiso desayunar`            | Lo que toca **después del desayuno**, sin culpa                                                                       |
| `¿qué le doy ahora?`            | El menú de la **franja de este momento** (o la siguiente si no hay una activa)                                        |
| `¿qué le doy de merienda?`      | El menú de **merienda** del plan                                                                                      |
| `¿cuánta agua?`                 | La meta de agua del plan (por ejemplo "entre 1,2 y 1,5 litros") y su hábito                                           |
| `¿puede comer pastel de cumpleaños?` | **"Tu plan no lo dice. Pregúntale a tu profesional."** — no inventa                                              |

**Lo importante:** el chat **nunca** debe proponer un alimento rojo (gaseosa, dulces, manzana durante
el descanso) ni inventar lo que el plan no dice. Si lo hace, anótalo — es justo lo que el gate busca.

## 3. Redirecciones (el chat NO responde eso, a propósito)

| Escribe esto                   | Deberías ver                                                |
| ------------------------------ | ----------------------------------------------------------- |
| `¿le subo la dosis de la B12?` | Redirección amable a tu **pediatra/nutricionista**          |
| `¿le cambio el medicamento?`   | Igual: te devuelve al profesional                           |
| `¿quién ganó el partido?`      | Redirección amable (fuera de tema)                          |

**Lo importante:** ninguna de estas tres debe recibir una respuesta médica ni inventada.

## Nota de privacidad para el gate

Cuando pruebes con la **dieta real** (la que te entregan aparte): el chat **no manda nada a la red**
— ni la dieta, ni lo que escribes, ni el registro del día. Lo que escribas en el **registro del día**
(las notas tipo "le dolió") el chat tampoco lo lee. Es una garantía del diseño, no una opción.
